# AI-Powered Workplace Productivity Assistant

## Project Overview

The AI-Powered Workplace Productivity Assistant is a digital productivity solution designed to support employees with common workplace tasks.

The project demonstrates how AI and prompt engineering can be applied to improve workplace communication, organisation, planning and research.

## Problem Statement

Employees often spend significant amounts of time performing repetitive tasks such as writing emails, summarising meetings, planning tasks and researching information.

The assistant provides a centralised solution that can help users complete these activities more efficiently.

## Key Features

### 1. Email Generator

Helps users create professional workplace emails based on a given topic.

### 2. Meeting Summariser

Helps organise meeting notes into key discussion points and action items.

### 3. Task Planner

Breaks workplace tasks into smaller and manageable steps.

### 4. Research Assistant

Provides a structured approach for researching workplace topics.

### 5. Workplace Chatbot

Provides general assistance with workplace-related questions.

## AI and Prompt Engineering

The project uses structured prompts that provide the AI with:

- A specific role
- Clear instructions
- User context
- Expected output
- Responsible AI requirements

The prompts are documented in the `prompts.md` file.

## Responsible and Ethical AI

Responsible AI is important when using AI in the workplace.

Users should:

- Verify AI-generated information.
- Avoid entering confidential information into public AI tools.
- Review AI-generated content before using it professionally.
- Be aware that AI can produce inaccurate or biased information.
- Keep human judgement involved in important decisions.
