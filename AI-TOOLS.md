# AI Tools Used

## ChatGPT

ChatGPT was used during the development of this project to assist with:

- Generating and improving workplace prompts
- Developing the project structure
- Creating example workplace workflows
- Improving documentation
- Exploring responsible AI practices

## GitHub

GitHub was used to:

- Store the project source code
- Track project development
- Manage project files
- Provide access to the project repository

## HTML, CSS and JavaScript

The project uses:

- HTML for the website structure
- CSS for the visual design
- JavaScript for interactive functionality

# Purpose of AI

The purpose of using AI in this project is to demonstrate how artificial intelligence can support everyday workplace productivity tasks such as communication, meeting management, planning and research.

# Responsible AI

AI-generated information should be reviewed by a human before being used in important workplace decisions.

Users should avoid entering confidential, private or sensitive company information into public AI tools.
